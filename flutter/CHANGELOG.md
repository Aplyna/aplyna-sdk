## 1.0.0

- `Purchases` API with RevenueCat-compatible names: configure, offerings and packages, purchase, customer info, restore, log in and out, customer attributes and update listeners, with the same error codes.
- Offerings from the Aplyna product catalog with live store prices.
- Customer attributes and app user ID.
- Clear network errors and last verified customer info when offline.
- Android: Google Play billing through the shared Kotlin core; fixed subscription plan replacement.
- The original `Aplyna.billing` API and the events, assignments and remote configuration API are unchanged.
